Antes de empezar

Preguntas sobre automatizaciones y BI

Definimos el flujo de trabajo, el origen de los datos y el seguimiento que necesita cada proceso.

¿Qué permite automatizar Manychat?

El servicio contempla respuestas a mensajes privados en Instagram y Facebook, con derivaciones según el objetivo definido, como llevar una consulta a WhatsApp. Para asistentes entrenados con información de la empresa, podés consultar el servicio de chatbots con IA. Comparar con un chatbot con IA ↗

¿Qué se necesita para trabajar mailing?

Se necesita una base de correos provista por el cliente o reunida a través de sus otros canales. El alcance puede incluir el objetivo del envío, las plantillas, la limpieza de la base y el orden de los envíos. Ver el servicio de mailing ↗

¿Se puede enviar un correo cuando alguien completa un formulario?

Sí. El mailing puede organizarse como un flujo automático que se inicia al completar un formulario, o como envíos a una base de contactos. El formulario, los datos que registra y el mensaje se definen según el objetivo. Conectar con una página web ↗

¿Qué aporta un informe avanzado con Business Intelligence?

Combina la lectura de resultados según los objetivos con acceso a tableros de seguimiento. Ayuda a revisar hallazgos, oportunidades y datos relevantes para marketing y decisiones comerciales. Conocer el informe avanzado con BI ↗
